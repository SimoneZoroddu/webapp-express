# WebApp Express

Backend REST API developed with Express.js and MySQL during my Full Stack Web Development training.

## Overview

A backend application built following MVC principles, featuring database integration, request validation, error handling and API endpoints for managing movie data and reviews.

## Features

- REST API development
- MySQL database integration
- MVC architecture
- Route management
- Custom middleware
- Request validation with Express Validator
- Error handling
- Environment variables configuration

## Project Structure

```text
controllers/
routes/
middlewares/
data/
public/
```

The project follows a modular structure with controllers, routes and middleware separation to improve maintainability and scalability.

## Installation

```bash
git clone https://github.com/SimoneZoroddu/webapp-express.git
cd webapp-express
npm install
npm run dev
```

## Environment Variables

Create a `.env` file and configure your database credentials.

```env
DB_HOST=
DB_USER=
DB_PASSWORD=
DB_NAME=
```
